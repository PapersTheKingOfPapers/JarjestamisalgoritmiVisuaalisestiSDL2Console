# JarjestamisalgoritmiVisuaalisestiSDL2Console
BubbleSort algoritmi visualisoitu SDL2lla

Repositorio sisältää jo kopion SDL2-2.26.5 versiosta.

Projekti käyttää säikeistystä BubbleSortin suorittamiseen, jotta renderöiminen olisi tasaista ja mukavaa.
Myös sen takia että SDL2 renderöimistä ei voinut säikeistää.
